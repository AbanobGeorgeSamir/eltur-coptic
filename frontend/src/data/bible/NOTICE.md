Arabic Bible text data

This directory contains all 66 books in the Smith–Van Dyck Arabic translation
(1865), sourced from the `ar/svd` data in:
https://github.com/midvash/bible-data/tree/d9fe1779447717bbfcb578e505b893125cad581c/versions/ar/svd

The source metadata identifies this translation as public domain. The
repository's code is MIT licensed; the Bible text carries its own license.
